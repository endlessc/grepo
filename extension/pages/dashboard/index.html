连接你的 GitHub

收藏在 GitHub 的几千个仓库，总在需要时想不起名字。grepo 将它们变成一份毫秒级检索的本地安全指挥舱。

权限与隐私保障

在 github.com/settings/tokens/new 生成，勾选 public_repo 即可读取公开 star 与 fork；需覆盖私有仓库再勾 repo。Token 仅保存在本机浏览器扩展存储中，绝不上传第三方服务器。
